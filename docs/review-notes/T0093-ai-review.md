# T0093 邪見經 AI 校验记录

校验者：claude-sonnet-5-5；翻译者：deepseek-v3.2。底本：sources/cbeta/T01n0093.xml。

## 已改

- 原文：与底本逐字比对，正文无差异。sid:008 末尾补卷尾題「佛說邪見經」，译文同步补。
- 分段：sid:006 末尾的「是故，阿難！我今歸汝。」是邪命外道的话，移到 sid:007 开头，译文同步移。
- 译文 sid:001：「我是這樣聽說的」改为「我是這樣聽佛說的」。
- sid:002：「異邪命」译为「邪命外道」，去掉「外道修行者」的说法；「𩮰角友」译为「少年時的朋友」并保留原字；「邪命聞已知之」译为「邪命外道聽了，明白了」。
- sid:003、004：删去原文没有的括注「（指佛陀）」「（不肯定回答）」「（佛的稱號）」；「命是身是、命異身異」译为「命與身是同一、命與身相異」；「不記說」统一译为「不作記說」；「無有命終」统一译为「沒有命終」。
- sid:005：「云何知」两处按原文译为「是怎樣知道」「這要怎樣知道」。
- sid:006：删去无依据的「（業）」「果報」「導致」，按原文「相應、等相應，如是趣、如是生，及後世」直译。
- sid:008：「為優婆塞」译为「作優婆塞（在家男居士）」，去掉「我願」；「法及比丘僧」去掉自加的「皈依法」重复和「僧團」说法；「歡喜而樂」按原文译。

## 留给人工复核

- sid:006「此邪見者，相應、等相應，如是趣、如是生，及後世」：句意不明，现按字面译，主语和「相應」所指待人工确认。
- sid:002「邪命聞已知之」：此处指邪命听了阿难的应允，还是已明白所问之意，译文暂按字面。
- sid:003「有此無有此」：字面译为「有此、沒有此」，含义待确认。
- 简转繁：本次译文直接用繁体写，未发现转错的字词。
