1. sid:002–004「我昔曾聞古仙所言：『有其五事……頌云：」「「『「和好行財賄……」』」「「准斯道理……』」」：底本引号层级如此（苦母语「」内引古仙语『』，颂又用「」），原文、译文都照底本，不改层级。
2. sid:003「和好行財賄，矯詐為毒術」：五事按「和好、行財賄、矯詐、為毒術、兵力」读，译为「講和修好、施行財賄，矯詐欺騙、使用毒術；最後才動用兵力」；也可读作「矯詐為毒術」一事，请确认。

4. sid:032「急遣隨親去」：译为「打發她們跟隨親人去」，按上下文是截手足后任其死去或驱遣，原文没有明说，照字面。
